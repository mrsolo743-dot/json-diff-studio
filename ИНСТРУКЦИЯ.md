# Инструкция: проверка и загрузка на GitHub

## 1. Проверить проект локально

Нужны Python 3.9+ и (для JS-тестов) Node.js 18+.

```bash
cd json-diff-studio

# тесты Python (ядро, CLI, отчёты, общие фикстуры, свойства)
python -m pip install pytest
python -m pytest

# тесты JS-порта
node --test web/tests/core.test.mjs

# попробовать CLI на примере
python -m json_diff_studio diff examples/before.json examples/after.json -k id -i "$.updatedAt" -t 1e-6
python -m json_diff_studio diff examples/before.json examples/after.json -k id -f html -o report.html
python -m json_diff_studio patch examples/before.json examples/after.json -k id -o patch.json
python -m json_diff_studio verify examples/before.json examples/after.json patch.json

# открыть веб-песочницу
python -m http.server 8000 --directory web
# → http://localhost:8000 (кнопка «Пример» загружает демонстрационные данные)
```

> В PowerShell шаблоны с `$` берите в одинарные кавычки: `-i '$.updatedAt'`.

Сквозные тесты интерфейса (необязательно):

```bash
python -m pip install playwright
python -m playwright install chromium
python -m pytest tests/e2e
```

Ожидаемый результат: все тесты зелёные (Python — 615, включая 9 e2e; JS — 29).

## 2. Создать репозиторий и загрузить код

1. На https://github.com/new создайте репозиторий **json-diff-studio**:
   - видимость Public;
   - описание: «Структурное сравнение JSON и JSON Patch (RFC 6902): CLI на Python + веб-песочница»;
   - **не** добавляйте README, .gitignore и License: они уже есть в проекте.
2. В папке проекта выполните:

```bash
git init
git add .
git commit -m "json-diff-studio 1.0.0: структурный diff JSON, JSON Patch, CLI и веб-песочница"
git branch -M main
git remote add origin https://github.com/mrsolo743-dot/json-diff-studio.git
git push -u origin main
```
